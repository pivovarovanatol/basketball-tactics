    Публикация на GitHub

    Сохранённые комбинации записываются в plays/ в репозитории. Нужен токен GitHub с правом записи в этот репозиторий. Он хранится только в этом браузере.

    Создать fine-grained токен: Repository access → только этот репозиторий, Permissions → Contents: Read and write.
