# Баскетбольная тактика

Схемы комбинаций с описаниями. Картинки лежат в [`diagrams/`](diagrams/), их можно открыть и переслать как есть.

![Кресты и скресты](diagrams/all-four-plays.png)

## Обозначения

- **O1–O5** — атака, **X** — защита
- Сплошная стрелка — рывок, пунктир — пас, линия с «Т» на конце — заслон
- Цифры в кружках — порядок действий

## Атака

| Схема | Суть | Английское название |
|---|---|---|
| [Нижний скрест](diagrams/01-lower-scissors.png) | Пас на O5 на линию штрафного, O3 и O4 по очереди режут крест-накрест между O5 и кольцом | split cuts / scissors |
| [Верхний скрест](diagrams/02-upper-scissors.png) | То же, но рывки скрещиваются над O5, ближе к мячу; удобнее хэндофф | split cuts / scissors |
| [Нижний крест](diagrams/03-lower-cross.png) | Заслон поперёк под кольцом для центрового, затем pin-down самому заслонщику | screen the screener, cross-down |
| [Верхний крест](diagrams/04-upper-cross.png) | Заслон поперёк на уровне элбоу, заслонщик выходит наверх | elbow cross screen |

## Пик-н-ролл

![Пик-н-ролл на элбоу](diagrams/elbow-pnr.png)

| Схема | Суть |
|---|---|
| [Расстановка](diagrams/06-elbow-pnr-setup.png) | Где стоят все десять игроков: O5 ставит заслон на X1 у элбоу, X5 в дропе, X4 — нижний страхующий |
| [Опции](diagrams/07-elbow-pnr-options.png) | Проход, ролл, поп и переводы в угол и на крыло — что выбирать в зависимости от того, кто помогает |
| [Против смены](diagrams/08-elbow-pnr-vs-switch.png) | Защита меняется — атакуем два мисматча: проход против большого, игра в посту против маленького, слип |
| [Против хеджа](diagrams/09-elbow-pnr-vs-hedge.png) | Большой выпрыгивает наверх — быстрый пас на ролл, шорт-ролл 4 на 3, отвод мяча, сплит |

## Заслон для ведущего сверху

![Заслон для ведущего сверху](diagrams/side-screen.png)

| Схема | Суть |
|---|---|
| [Расстановка и проход](diagrams/10-side-screen-setup.png) | O1 и O2 сверху, слабая сторона перегружена. O5 с блока ставит заслон на X1, O1 финтит и уходит через заслон по пустой стороне на лэй-ап |
| [Если смена](diagrams/11-side-screen-switch.png) | O5 проваливается в зону против маленького X1, O1 отдаёт под кольцо или атакует большого |
| [Ресет на другую сторону](diagrams/12-side-screen-reset.png) | Защита осталась при своих — пас на O2, все переходят на другую сторону, и то же самое повторяется |

## Как перерисовать

Все схемы генерируются скриптом, правки — в [`tools/make_diagrams.py`](tools/make_diagrams.py):

```bash
pip install cairosvg
python3 tools/make_diagrams.py
```
