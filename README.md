# Баскетбольная тактика

Схемы комбинаций с описаниями. Каждую картинку можно открыть и переслать как есть.

| | Раздел | Что внутри |
|---|---|---|
| 🔀 | [Кресты и скресты](#кресты-и-скресты) | Ножницы через высокий пост, заслон поперёк и screen the screener |
| 🔁 | [Пик-н-ролл на элбоу](#пик-н-ролл-на-элбоу) | Расстановка, опции атаки, игра против смены и хеджа |
| ⬆️ | [Заслон для ведущего сверху](#заслон-для-ведущего-сверху) | Заслон с блока, проход по пустой стороне, смена, ресет |
| 🛡️ | [Защита: pin-down](#защита-pin-down) | Частая ошибка, когда защитники не меняются |

**Обозначения:** O1–O5 — атака, X — защита. Сплошная стрелка — рывок или проход, пунктир — пас, линия с «Т» на конце — заслон (упирается в защитника, на которого его ставят), оранжевым — движение защиты, цифры в кружках — порядок действий или номер опции.

## Защита: pin-down

<img src="diagrams/05-pin-down-defense.png" alt="Pin-down на слабой стороне" width="480">

Частая ошибка без смены: оба защитника уходят за игроком, который выходит из угла, и заслонщик остаётся открытым. Как правильно: X2 прилипает к своему игроку и идёт за ним, X3 на шаг показывает себя и сразу возвращается к заслонщику.

## Как перерисовать

Все схемы генерируются одним скриптом. Чтобы поправить или добавить схему, правки вносятся в [`tools/make_diagrams.py`](tools/make_diagrams.py):

```bash
pip install cairosvg
python3 tools/make_diagrams.py
```
