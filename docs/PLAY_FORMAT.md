# Формат комбинации (`format: 1`)

Каждая комбинация — файл `plays/<id>.json`. `id` совпадает с именем файла, по нему работают ссылки (`?play=<id>`),
поэтому при переименовании он не меняется.

```json
{
  "format": 1,
  "id": "03-lower-cross",
  "name": "Нижний крест",
  "intro": "Заслон поперёк, а потом заслон самому заслонщику.",
  "updated": "2026-11-10T00:00:00.000Z",
  "start": {
    "pos": { "O1": [65, 150], "O2": [190, 110], "…": "…", "X5": [250, 274] },
    "ball": { "holder": "O1" }
  },
  "steps": [
    { "cap": "1. O3 ставит заслон поперёк зоны на X5.", "dur": 1366, "arc": 0,
      "moves": { "O3": [231, 278], "X3": [214, 262] }, "ball": null, "screens": ["O3"] },
    { "cap": "2. O5 выходит на ближний к мячу блок.", "dur": 1638, "arc": 0,
      "moves": { "O5": [142, 242] }, "via": { "O5": [195, 210] }, "ball": null },
    { "cap": "Пас на O3.", "dur": 1820, "arc": 59, "moves": {}, "ball": { "holder": "O3" }, "shot": "lob" },
    { "cap": "Бросок.", "dur": 1340, "arc": 46, "moves": {}, "ball": { "point": [190, 292] }, "shot": "shot" }
  ]
}
```

## Поля

| Поле | Что это |
|---|---|
| `id` | Имя файла без `.json`: латиница, цифры, дефисы. |
| `name` | Название в списке. |
| `intro` | Подпись перед первым шагом (необязательно). |
| `start.pos` | Где стоят все десять игроков: `O1`–`O5` (атака) и `X1`–`X5` (защита). |
| `start.ball` | У кого мяч: `{ "holder": "O1" }`. |
| `steps[]` | Шаги по порядку. |

### Шаг

| Поле | Что это |
|---|---|
| `cap` | Подпись к шагу. |
| `moves` | Кто куда переместился за шаг. Остальные стоят на месте. Если мяч остаётся у игрока, который двигается, — это ведение. |
| `via` | Необязательно. Контрольная точка изогнутого рывка для игрока (квадратичная кривая), как в схемах. |
| `ball` | Куда идёт мяч: `{ "holder": "O5" }` — пас игроку, `{ "point": [190, 292] }` — в кольцо (бросок) или на пол, `null` — остаётся у того же игрока. |
| `shot` | Необязательно: `"lob"` — навес (высокая передача, скип-пас), `"shot"` — бросок в кольцо. Без него — обычный пас. |
| `screens` | Необязательно: кто из пробежавших ставит заслон (стрелка с «Т» на конце). |
| `dur` | Длительность в миллисекундах при скорости 1×. |
| `arc` | Высота полёта мяча на 2D-доске (единицы рисунка). |

## Координаты

Те же, что в схемах (`tools/make_diagrams.py`): половина площадки в рамке 380 × 330. Площадка — x от 20 до 360
(15 м), y от 20 (центральная линия) до 310 (лицевая). Кольцо — (190, 292), 1 м ≈ 22,7 единицы.

## plays/index.json

```json
{
  "folders": ["Атака против личной", "Атака против личной/Кресты и скресты", "Защита"],
  "plays": [
    { "id": "03-lower-cross", "name": "Нижний крест", "folder": "Атака против личной/Кресты и скресты",
      "file": "03-lower-cross.json", "updated": "2026-11-10T00:00:00.000Z" }
  ]
}
```

- `folders` — все папки, в том числе пустые; `/` разделяет подпапки.
- `folder` у комбинации — где она показывается в дереве (`""` — верхний уровень). В самом файле папка не хранится.
- Порядок в папке и порядок папок — как в этом списке.
- Комбинации из схем генерирует `python3 tools/make_plays.py` (перезаписывает `plays/`). После ручной правки
  JSON-файлов индекс обновляет `node scripts/build-index.mjs`.
